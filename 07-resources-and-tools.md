# 7. Resources & Tools

## Environment Options

### Spektra Systems (External, Turnkey)

**Best for**: Multi-customer hackathons where you need hands-on environments at scale.

**What's included per attendee:**
- Dedicated environment with:
  - Microsoft Copilot Studio
  - Copilot for Microsoft 365
  - Microsoft 365 Business Premium licenses
- Pre-built industry scenarios available
- Environment lifetime: **24 hours** (reset post-event, not for production)



**Include in request:**
- Event date & time
- Partner name
- Industries selected
- Expected number of attendees
- Event format
- Primary contact
- Primary IT contact

**Operational tips:**

> 🔍 **[Enrichment]** From event execution experience: Plan for early login access. Prepare printed login instructions per table. Consider a dedicated SharePoint site per tenant for materials distribution.

### CDX (Customer Demo Experience)

**Best for**: Smaller events, PSA-led demos, proof-of-value sessions.

CDX enables partners to provision fully functional demo environments for Microsoft cloud solutions.

**What's included:**
- Pre-configured M365 demo tenants
- Copilot + Copilot Studio capabilities
- Realistic scenarios without impacting production tenants

**How to access:**
- Request portal: [cdx.transform.microsoft.com](https://cdx.transform.microsoft.com)
- Copilot demo tenant: `aka.ms/copilotdemotenant`
- Requires correct security group membership
- Subject to license availability and SFI (Secure Future Initiative) controls

**Limitations for hackathons:**
- Not explicitly designed for multi-team, multi-environment scale
- No guarantee of one-tenant-per-team
- No automatic environment reset after event
- Only includes Copilot Studio license — **no M365 corporate license**, so agents cannot be published to Teams channels (testing only, not full showcase)

> ⚠️ **Field Insight:** CDX environments lack the full M365 corporate license needed to publish agents to Teams. This makes it impossible to demonstrate the end-to-end "agent in a Teams channel" experience, which is an important showcase moment during hackathons. If agent publishing is part of the plan, use Spektra or a customer/partner environment instead. (May 2026, adesso hackathon debrief)

> 🔍 **[Enrichment]** CDX works best for facilitated demos and PSA workshops, less so for large hands-on hackathons where each table needs an isolated environment. Consider Spektra for 20+ participant events.

### Customer Environment (Enterprise 1:1)

**Best for**: Enterprise customers with existing opportunity; turns hackathon into a real pilot.

**Requirements:**
- Existing opportunity in place
- Customer-approved access to data and systems
- IT admin available for setup and troubleshooting
- Sufficient lead time for license provisioning

**License options:**
- Trial licenses available for 60–90 days when opportunity is in place
- Use internal tools to request trial environments

> ⚠️ **Field Insight:** Working in the customer's real environment is much more powerful — you have real data and real system access. But it requires more prep time and a technical contact from the customer to grant access to the partner.

> 🔍 **[Enrichment]** Trial license duration (60 vs 90 days) and exact request workflow are not formally standardized in hackathon guidance. The process is implied from field practice but varies by region and opportunity type.

### Partner Benefits (MAICPP)

> ⚠️ **Field Insight:** Encourage partners to invest in their **own permanent demo environment** rather than relying solely on free/temporary options. When partners pay for an environment, they are incentivized to maximize its use — generating leads, running demos, pitching customers. Free environments tend to be treated as disposable. Shared investment also aligns Microsoft and partner objectives around monetization. (May 2026, adesso hackathon debrief)

Partners in the Microsoft AI Cloud Partner Program can use their own benefits:

**Microsoft 365 Copilot Licenses included with:**
- Solution Partner Modern Work designation: 5 × Microsoft 365 Copilot licenses
- Specialization Modern Work designation: 5 × Microsoft 365 Copilot licenses

**Permitted uses:**
- Internal use (development, test, demo, sandbox, production for internal business)
- Demonstration purposes (sales/marketing to showcase products — must be on partner hardware with partner supervision)

**Reference**: [View and Use Your Cloud Services Benefits - Partner Center](https://learn.microsoft.com/partner-center)

## Azure Accelerate (1:1 Customer Hackathon Track)

While this knowledge base focuses on M365 Agent hackathons, partners should be aware of the Azure Accelerate option:

- Dedicated 1:1 customer hackathon format (partner-led)
- Single customer works on their own use cases
- Supported by Microsoft and partner experts
- **Azure Sandbox**: Up to $5,000 in Azure credits for the hackathon
- Workload-agnostic (AI Apps, Data Platform, Modernization, Infrastructure, GitHub Copilot)
- URL: [Azure Accelerate](https://azure.microsoft.com)

### MCI / Accelerate Nomination

To nominate customers for MCI (Microsoft Customer Immersion) engagements post-hackathon:
- Work with the Microsoft Account Team (AE/CSM) to identify eligible customers
- MCI options include: Copilot + Power **Accelerate** (presales) and Copilot + Power **Deployment Accelerator** (post-sales)
- Nomination is typically driven by the Microsoft field team based on customer interest captured in the Book of Agents
- Contact your regional MCI coordinator or PSA for the current nomination process (varies by region)
