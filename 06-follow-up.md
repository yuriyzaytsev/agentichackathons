# 6. Follow-Up & Conversion

## Post-Event Timeline

| When | Action | Owner |
|------|--------|-------|
| **D-Day** | Compile Book of Agents (while jury deliberates) | Event Coordinator |
| **D-Day** | Share Book of Agents with attendees | Partner |
| **+1 week** | Summarize scenarios per table | Partner (Microsoft support) |
| **+1 week** | Evaluate customer interest levels | Partner + Microsoft AE |
| **+1 week** | Propose tailored follow-up per customer | Partner |
| **+2-4 weeks** | Schedule O.O. follow-up workshops | Partner + Microsoft AE |
| **+2-4 weeks** | Create leads in Partner Center (#PartnerGTM) | Partner |
| **+3-4 weeks** | Nominate customers to MCI (if relevant) | Microsoft |
| **+3-4 weeks** | Engage Microsoft AE/CSM for deeper conversations | Partner + Microsoft |

## Book of Agents

### What It Is

The **Book of Agents** is the primary deliverable from a hackathon — a compiled document of all agent use cases and solutions created during the event. It serves as:
- Tangible **customer takeaway**
- **Anchor for closing discussion** ("what next?")
- **Input to MCI nomination** and cosell follow-up
- **Evidence of customer intent** for seller-partner joint planning

### What It Contains

One entry per team/agent:

| Field | Description |
|-------|-------------|
| Business problem / scenario | What challenge does this agent address? |
| Agent name + description | What does it do? |
| Target users / role / industry | Who benefits? |
| Agent instructions | How is the agent configured? |
| Knowledge sources | SharePoint, D365, websites, etc. |
| Triggers & actions | If using Copilot Studio flows |
| Expected value / outcome | What business value does it deliver? |

### Format & Production

> 🔍 **[Enrichment]** From the Facilitator Guide: The Book of Agents is a **single PowerPoint** compiled at the end of the day. Created while judges deliberate. Use the Group Hackathon Template for consistency. Often pre-staged via a SharePoint page with templates. Share with attendees **same day** if possible. (Agent Hackathon Facilitator Guide)

**Process:**
1. Teams prepare pitch decks during hackathon
2. Event coordinator compiles entries during jury deliberation
3. Final document shared with all attendees
4. Becomes input for all follow-up activities

## Lead Qualification & Conversion

### Use Case Library (Partner-Published)

> ⚠️ **Field Insight:** Recommend partners publish hackathon-created use cases (not finished products, but scenarios and ideas) on their own website. Over multiple events this builds a publicly visible library that generates inbound leads without extra effort. It positions the partner as a thought leader and gives customers something tangible to react to. Partners don't need to be asked to "do something for Microsoft" — this directly benefits their own pipeline. (May 2026, adesso hackathon debrief)

### Immediate Follow-Up (+1 Week)

**Summarize and evaluate:**
- Summary of each table's scenarios explored during ideation
- Customer interest level per scenario (Low / Medium / High)
- Alignment to repeatable use cases
- Fit to partner service offering

**Propose next steps per customer:**

| Customer Interest | Recommended Next Step |
|-------------------|----------------------|
| **High** | One-on-one Agent-a-thon with customer environment; Copilot Accelerate |
| **Medium** | Partner-led workshop to refine and deepen scenarios |
| **Low** | Nurture via content; invite to future events |

### Conversion Motions

```
Agent Hackathon → Book of Agents → Qualify Interest → Next Step
                                                      ↓
                                    ┌─────────────────┼──────────────────┐
                                    ↓                 ↓                  ↓
                              O.O. Agent-a-thon   Copilot Accelerate   Partner Services
                              (1:1, deep dive)    (MCI nomination)     (Implementation)
```

### O.O. (One-on-One) Engagement

Execute a personalized, on-site Agent-a-thon with the customer:
- Can use the customer's own environment (more powerful)
- Partner and Microsoft AE are looped in
- Delivers presales activities progressing M365 Copilot, Copilot Chat, and Agent opportunities

### MCI (Microsoft Customer Immersion) Nomination

**Important**: The hackathon itself is NOT MCI. It is a **qualification and intent-shaping step**.

Flow: Hackathon → Book of Agents → Customer nomination for MCI workshop

Typical MCI next steps:
- **Copilot + Power Accelerate** (presales)
- **Copilot + Power Deployment Accelerator** (post-sales)
- In-a-day or multi-day workshops (partner-led or field-led)

> 🔍 **[Enrichment]** From corporate guidance: Hackathon = "Inspire & Design" stage; Accelerate = "Empower & Achieve" stage. The hackathon positions the customer for deeper engagement, not as a standalone event.

## Cosell & #PartnerGTM

### How to Create Opportunities

**Final step**: Drive transformation and share cosell opportunities with **#PartnerGTM**.

1. Partner raises cosell opportunities for identified agents in **Partner Center**
2. Use **#PartnerGTM** in the campaign ID field when sharing opportunities
3. Opportunities aligned to MCEM (Microsoft Customer Engagement Methodology) stages
4. Proper partner association required to count for impact & incentives

### Why This Matters
- Tracks event-to-pipeline conversion
- Enables Microsoft AE engagement
- Unlocks potential incentives for partners
- Demonstrates event ROI

## Measuring Success

### Tier 1: Event Metrics (Hard)

| Metric | Description |
|--------|-------------|
| # Customers attending | Total unique customer organizations |
| # Attendees | Total participants |
| # Agents/scenarios built | Teams that produced working output |
| # Scenarios pitched | Quality of pitches (jury scoring) |
| Book of Agents produced | Yes/No + quality |

### Tier 2: Qualification Metrics

| Metric | Description |
|--------|-------------|
| Customer interest level per scenario | Low / Medium / High per table |
| # Follow-up workshops booked | Conversion from event to next step |
| Alignment to repeatable use cases | Partner IP potential |
| Fit to partner service offering | Revenue opportunity |

### Tier 3: GTM Metrics

| Metric | Description |
|--------|-------------|
| # Partner Center leads created | With #PartnerGTM tag |
| # Opportunities linked to event | Traced pipeline |
| # MCI nominations | Customers entering Accelerate |
| Time to first follow-up | Speed of conversion |

> 🔍 **[Enrichment]** No Microsoft document states numeric conversion benchmarks (e.g., "X% of attendees convert to pipeline"). Qualitative guidance on expected motion exists (event → workshop → opportunity). Emphasis is on **capturing leads immediately** and tagging them. Any percentage benchmarks would need to be established per region/partner maturity.

### Success Definition (Microsoft-Aligned)

| Level | Definition |
|-------|------------|
| **Event success** | Qualified next conversation booked |
| **GTM success** | Lead created + AE looped in |
| **Strategic success** | Repeatable scenario enters partner offering |

## Feedback Collection

Distribute an event feedback form to attendees covering:
- Overall satisfaction
- Most valuable session/component
- Interest in follow-up engagement
- Net Promoter Score
- Suggested improvements
